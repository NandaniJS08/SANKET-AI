# SIH26k

An intelligent web platform featuring analytics, predictions, alert management, and AI assistance.

## Project Structure

```
SIH26k/
├── frontend/     # React 19 + Vite + Tailwind CSS v4 frontend
├── backend/      # Backend API services
└── README.md
```

## Getting Started

### Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Backend Setup

Backend services and APIs will be configured in the `backend/` directory.
